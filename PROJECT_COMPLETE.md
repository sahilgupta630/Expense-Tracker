## 🚀 How to Run

### Quick Start (3 Commands)

**Terminal 1:**
```bash
mongod
```

**Terminal 2:**
```bash
cd backend
npm run dev
```

**Terminal 3:**
```bash
cd frontend
npm run dev
```

**Then open:** http://localhost:5173

### Even Faster (Windows)
Just double-click `start.bat` in the project root!
